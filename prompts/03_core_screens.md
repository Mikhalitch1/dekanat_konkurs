# Этап 3. Ядро: вход, профиль, расписание, успеваемость
Задачи:
1. Экран входа с понятными ошибками, профиль (ФИО, факультет, направление, курс, группа).
2. Расписание: день и неделя, аудитория, преподаватель, заметные переносы и отмены, экспорт .ics.
3. Успеваемость: список дисциплин со светофором, деталь дисциплины (баллы, контрольные), сессия.
4. «Сегодня»: пары и дедлайны одним потоком.
5. Загрузка, пусто, ошибка на каждом экране. Все данные берутся с API по сессии.
Приёмка: сценарий «вошёл → увидел сегодня → открыл расписание → открыл оценки» без ошибок на 360 px; данные студентов 1 и 2 различаются.
