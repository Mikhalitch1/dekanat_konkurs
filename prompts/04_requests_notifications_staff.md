# Этап 4. Заявки, уведомления, кабинет сотрудника
Задачи:
1. Каталог типов заявок и справок, форма подачи с валидацией.
2. Список заявок и деталь с треком статусов (как у посылки), ожидаемый срок.
3. Уведомления: объявления, дедлайны, изменения расписания, отметка «прочитано», бейдж на вкладке.
4. Кабинет сотрудника: очередь заявок с фильтрами, смена статуса с комментарием, публикация объявления.
5. При смене статуса студент получает уведомление.
Приёмка: студент подал заявку → сотрудник перевёл в «в работе» и «готово» → студент увидел трек и уведомление; чужие заявки недоступны.
