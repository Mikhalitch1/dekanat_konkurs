# Этап 0. Импорт расписания МГИМО
Входной файл: data/schedule/<имя файла>. Сначала изучи его формат и покажи мне краткий разбор: структура, колонки, поля, какие группы и недели присутствуют, что неоднозначно. Код не пиши до моего «ок».
Затем:
1. Напиши скрипт scripts/import-schedule (TypeScript), который превращает файл в записи schedule_entries, disciplines и groups по docs/DATA.md. Скрипт идемпотентный и не падает на пустых и странных строках, а пишет их в отчёт.
2. Используй из файла только публичную учебную структуру: группы, дисциплины, время, аудитории, чётность недель. Имена преподавателей заменяй псевдонимами через стабильное отображение (одно настоящее имя = один вымышленный), чтобы не использовать реальные ФИО.
3. Для студентов 1 и 2 назначь две разные реальные группы из файла, чтобы расписания различались. Остальные данные студентов вымышленные.
4. Даты занятий строятся от текущей недели, чтобы демо выглядело актуально. Переносы и отмены добавляй сидером как вымышленные.
5. Исходный файл не публикуй в открытом репозитории, если это не публичные данные, и не клади его в сборку фронтенда. Добавь data/schedule в .gitignore и сохрани сгенерированный сид без реальных имён.
6. Напиши тест на импорт и отчёт о покрытии.
Приёмка: npm run db:seed поднимает расписание двух групп; в БД и сидах нет реальных ФИО преподавателей.
