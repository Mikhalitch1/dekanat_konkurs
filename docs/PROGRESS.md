## 2026-11-12–15 — реализация и проверка этапа 0

- Реализованы TypeScript-импортёр XLSX, обезличивание всего текста, отчёт качества, совместимая с PostgreSQL миграция, локальная PGlite и переносимый обезличенный сид. Исходный XLSX оставлен на месте и исключён из Git.
- package.json, конфигурации TypeScript/ESLint/Vitest и минимальная БД добавлены уже на этапе 0 для `db:migrate`, `db:seed`, lint, typecheck и тестов. Это не начало этапа 1: API, вход, интерфейс и Docker ещё не реализованы.
- Подтверждённые правила: C:D — обе недели; только C или D — соответствующая неделя; вертикальное объединение занятия — от начала первой до конца последней строки; пустая ячейка вне объединения — пары нет. Объединённая B задаёт один интервал нескольким вариантам текста.
- Единственная константа первой чётности — `FIRST_WEEK_PARITY` в config/schedule.ts, по умолчанию odd. Занятия строятся на две недели от московского понедельника текущей недели. Все даты из текста удаляются и записываются в отчёт; годы автоматически не исправляются. Курс, направление и факультет берутся из шапки, без пересчёта по текущему году.
- Сид: Артём Тестов — ТИГ(б)-О-23/1, Лина Образцова — ФЭТ(б)-О-23/1; оба второго курса по шапке и подгруппы I. Для ТИГ выбраны английский 2-29 и французский 2-4(2); для ФЭТ — английский 2-22 и испанский 2-5(2). Выбор хранится в БД, языковая группа задаётся сочетанием языка и номера.
- Допущение для немаркированных строк под одним объединённым временем: это параллельные альтернативные варианты; для демо выбран вариант 1. Источник не подтверждает, что они являются факультативами. Эвристика отражена в `elective_option` и предупреждениях; остальные варианты сохранены, но не попадают в выборку этих студентов.
- Импортированы 15 групп, 57 псевдонимов преподавателей, 234 дисциплины и 1080 уникальных записей. Распознано 443/446 непустых якорных ячеек — 99,33%; кандидатов в занятия — 374/377, 99,20%. Все 3 исключения перечислены в docs/SCHEDULE_IMPORT_REPORT.md и машинном отчёте.
- Главный агент вручную сопоставил 10 случайных ячеек (seed 20261112) с непосредственным чтением XML исходного XLSX, без функции импортёра: 10/10 совпали. Метод и таблица проверки опубликованы в docs/SCHEDULE_IMPORT_REPORT.md; скриншоты Excel не делались.
- Последние проверки 2026-11-15: lint, typecheck, build — успешно; Vitest 23/23 без пропусков при доступном исходнике. Покрытие V8: statements 94,32%, branches 85,02%, functions 97,43%, lines 97,95%.
- `npm run db:migrate` и `npm run db:seed` выполнены с локальной PGlite: по 35 отобранных занятий у каждого демонстрационного студента. Повторный сид не создаёт дубликатов. Отдельный запуск из обезличенного сида в изолированном временном каталоге без XLSX также дал по 35 занятий.
