## Проверенные результаты до отката

- API security tests: 14/14 на PGlite и отдельно 14/14 на PostgreSQL 17 в Docker. Общий прогон до последнего исправления клиента: 37/37. Миграции и сид успешно выполнены на Docker PostgreSQL теми же SQL и функциями; CLI использовал только PostgreSQL. PGlite перенесён в devDependencies для тестов.
- Проверены серверные роли, сессионный владелец, 404 на чужую заявку/оценку, 401 без сессии, отсутствие source_* и password_hash в расписании и ответах. Проверены httpOnly/Secure/SameSite=Lax, серверное хранение хэша токена, срок жизни, ротация и отзыв сессии при выходе.
- CSRF-токен и Origin обязательны для POST, включая вход. Пароли из окружения хэшируются argon2id. Лимиты по IP и логину проверены; найденный ответ 500 вместо 429 исправлен одной попыткой и подтверждён повтором 14/14.
- Независимый XML-список из 72 исходных фамилий: аудитор проверил 44 текстовых файла и не нашёл совпадений. Пять секретных значений из .env также не обнаружены в проверенных артефактах; сами значения не выводились.
- Соответствие ФИО и псевдонимов существует только в памяти импортёра. Файл исходного расписания сам содержит реальные фамилии и остаётся локальным исключённым источником; утверждение об отсутствии сохранённой таблицы соответствий не означает отсутствия фамилий в исходном XLSX. БД, сид и журналы такого соответствия не содержат по выполненным проверкам. Логи запросов API отключены.

## Находки и ограничения

1. HIGH: отложенный ответ расписания аккаунта A мог обновить экран после выхода и входа B. Источник: apps/web/src/App.tsx, loadSchedule/signOut. Главный агент добавил AbortController и проверку поколения запроса для success/error/finally, инвалидацию при выходе и смене пользователя, отдельную регрессионную проверку. Lint после правки прошёл; полный тест и HTTPS-проверка после неё не завершены. Исправление находится только в резервной копии, не объявляется окончательно проверенным.
2. За Nginx trustProxy=false агрегирует клиентов в IP-лимите. Поддельный X-Forwarded-For лимит не обходит; это ограничение точности и удобства, требующее согласованной настройки доверенного прокси перед публичным развёртыванием.
3. Полный Docker/HTTPS-стенд не поднят: Buildx дважды завершился ошибкой gRPC-заголовка с non-printable ASCII. Проверки браузера, HTTPS smoke и итоговый аудит исправленного клиента не состоялись.
