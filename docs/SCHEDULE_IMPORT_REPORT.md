## Полнота распознавания

Знаменатель — все непустые якорные ячейки C/D со строки 14 на 15 видимых листах. Объединённый диапазон считается один раз, по верхней левой ячейке. Пустые ячейки, заголовки, дни и время не являются текстом занятия и в знаменатель не входят. Восемь скрытых листов другого учебного года перечислены в skipped_sheets и не импортируются.

## Сид и фильтрация

- Артём Тестов: ТИГ(б)-О-23/1, курс 2 и направление из шапки; подгруппа I, английский 2-29, французский 2-4(2).
- Лина Образцова: ФЭТ(б)-О-23/1, курс 2 и направление из шапки; подгруппа I, английский 2-22, испанский 2-5(2).
- Для разных текстов под одним объединённым временем без явной подгруппы принято допущение: это параллельные альтернативные варианты. Для демо выбран вариант 1; остальные сохранены в БД и отмечены предупреждениями, но не попадают в расписание этих студентов. Поле elective_option отражает это допущение, а не подтверждённый статус факультатива.
- Номер языковой группы хранится вместе с языком в выборе студента, поскольку один номер встречается у разных языков. Происхождение и полный текст ячейки не возвращаются студенческой выборкой.
- Миграция и повторный сид идемпотентны. Проверено заполнение локальной PGlite, а также запуск из одного обезличенного сида и миграции в отдельном временном каталоге без XLSX: обе группы получают по 35 занятий.

## Проверки и ограничения

Последний полный прогон: lint, typecheck, build — успешно; Vitest — 23/23 без пропусков при доступном исходнике. Покрытие V8: statements 94,32%, branches 85,02%, functions 97,43%, lines 97,95%.

Тест приватности проверяет БД, сид, машинный отчёт и SCHEDULE_FORMAT.md по исходным фамилиям в памяти. Независимый аудитор другим способом извлёк 72 контрольные фамилии из XML всех листов: в сиде и обоих проверенных документах 0 совпадений. После записи локальной БД главный агент повторил независимую XML-проверку: в снимке всех пяти таблиц тоже 0 совпадений по 72 фамилиям. В локальной БД подтверждены 15 групп, 2 студента и 1080 записей. Реальные имена не сохранены в журнале или контрольном списке репозитория. Без XLSX тест по исходным фамилиям явно пропускается; синтетические тесты обезличивания продолжают выполняться.

При аудите закрыта находка о возврате полного source_text: студенческий DTO теперь содержит только отобранную запись без четырёх source_* полей. Незакрытых критичных, высоких и средних находок этапа 0 нет. API, вход, сессии, CSRF, браузерный интерфейс и контейнерный PostgreSQL ещё не реализованы: это следующие этапы.
