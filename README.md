# Цифровой деканат будущего

Личный кабинет студента и кабинет сотрудника деканата. Конкурсный концепт для «MGIMO AI Challenge», не официальный сервис вуза. Интерфейс на русском, все данные вымышленные.

**Работающий прототип:** https://dekanat.testvless.space (тестовые аккаунты передаются в описании конкурсной работы).

## Что внутри
- **Студент:** вход и профиль, «Сегодня», расписание (в календарь .ics), успеваемость со светофором и объяснением, заявки и справки с треком статуса и QR-проверкой, уведомления и новости с картинками, события с записью и баллами за внеучебную деятельность, портфолио, библиотека, помощник.
- **Сотрудник деканата:** очередь заявок, поиск студентов, правка профилей и баллов, изменения в расписании, мероприятия (создание, итоги и начисление баллов), новости.
- Мобильная версия от 360 px, светлая и тёмная темы.

## Технологии
React + Vite + TypeScript (интерфейс), Node.js + Fastify + zod (API), PostgreSQL (данные), Docker Compose, Vitest.

## Безопасность
- Идентификатор студента берётся только из серверной сессии; чужие ресурсы возвращают 404; роли проверяются на сервере.
- Пароли хранятся хэшем argon2id; сессии в HttpOnly-cookie, CSRF-токен и проверка Origin.
- СНИЛС и паспортные данные (вымышленные) шифруются в БД (AES-256-GCM), ключ только в окружении сервера; раскрытие фиксируется в журнале доступа.
- Секреты не хранятся в репозитории: `.env` игнорируется, образец — `.env.example`.

## Запуск у себя за три команды
Нужен только **Docker** (Docker Desktop на Mac и Windows или Docker Engine с Compose v2 на Linux). На Windows запускайте из WSL или Git Bash.

```bash
git clone https://github.com/Mikhalitch1/dekanat_konkurs.git
cd dekanat_konkurs
./start.sh
```

Скрипт сам создаёт секреты (`.env`, в git не попадает) и локальный сертификат, собирает контейнеры (первый запуск 3–6 минут) и печатает адрес **https://localhost:8443** и пароли тестовых аккаунтов (студент, студентка, сотрудник; данные вымышлены). Браузер предупредит о самоподписанном сертификате: «Дополнительно» → «Продолжить».

- Остановить: `docker compose down`; остановить и стереть данные: `docker compose down -v`.
- Другой порт: `HTTPS_PORT=9443 ./start.sh`.
- Если порты заняты или нужен Node-путь: `npm ci && npm run setup:local && docker compose up --build`.
- Проверки для разработчика: `npm run lint`, `npm run typecheck`, `npm test`.
- Развёртывание на сервере: [deploy/](deploy/) и `docker-compose.prod.yml`.
